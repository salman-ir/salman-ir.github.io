Kebijakan Privasi

Terakhir diperbarui: 13 November 2026
ID Paket Aplikasi: id.keluarga.tumbuh_pintar

Kebijakan Privasi ini menjelaskan bagaimana aplikasi Kidi menangani informasi pengguna. Kidi dirancang sebagai aplikasi belajar anak dan pemantau tumbuh kembang balita yang mengutamakan privasi keluarga serta bekerja secara luring (offline-first).

1. Data yang Disimpan di Perangkat

Seluruh data utama aplikasi disimpan secara lokal di perangkat Anda, termasuk:

  • Profil anak yang dimasukkan oleh orang tua (seperti nama panggilan, tanggal lahir, atau jenis kelamin untuk perhitungan kurva tumbuh kembang).
  • Catatan pengukuran tumbuh kembang (berat badan, tinggi badan, lingkar kepala) dan riwayat belajar anak.
  • PIN orang tua yang disimpan dalam bentuk hash kriptografis (tidak disimpan sebagai teks biasa).

Pengembang tidak memiliki server sendiri dan tidak mengumpulkan, menjual, atau membagikan data tersebut ke pihak ketiga mana pun.

2. Cadangan Opsional ke Google Drive

Orang tua dapat memilih secara sukarela untuk mengaktifkan fitur pencadangan (backup) melalui Google Sign-In dan Google Drive API:

  • Kidi hanya meminta akses ke folder aplikasi tersembunyi (drive.appdata) di akun Google Drive pribadi milik orang tua.
  • Aplikasi tidak dapat melihat, membaca, atau mengubah file lain di Google Drive Anda.
  • Fitur ini dilindungi di balik kendali orang tua (PIN) dan dapat dimatikan atau diputuskan tautannya kapan saja melalui pengaturan aplikasi.

3. Tidak Ada Iklan dan Pelacakan

  • Kidi tidak menampilkan iklan apa pun.
  • Kidi tidak menggunakan SDK analitik atau pelacakan pihak ketiga untuk memantau perilaku anak maupun orang tua.

4. Privasi Anak (Families Policy)

Aplikasi ini dibuat untuk digunakan oleh anak di bawah bimbingan orang tua. Kami tidak secara sadar mengumpulkan informasi pribadi anak melalui internet ke server pengembang. Pengelolaan profil anak dan fitur cadangan akun Google sepenuhnya berada di bawah kendali orang tua.

5. Penghapusan Data

Anda memiliki kendali penuh atas data Anda:

  • Menghapus data lokal dapat dilakukan dengan menghapus data aplikasi di pengaturan Android atau menghapus aplikasi Kidi dari perangkat.
  • Menghapus data cadangan di Google Drive dapat dilakukan dengan mencabut akses aplikasi Kidi melalui pengaturan akun Google Anda (Google Account → Security → Third-party apps with account access) atau menghapus data aplikasi tersembunyi di Google Drive.

6. Perubahan Kebijakan Privasi

Kebijakan Privasi ini dapat diperbarui sewaktu-waktu apabila ada penambahan fitur baru. Setiap perubahan akan ditampilkan pada halaman ini dengan tanggal pembaruan terbaru.

7. Kontak Pengembang

Jika Anda memiliki pertanyaan mengenai Kebijakan Privasi ini, silakan hubungi pengembang melalui repositori GitHub resmi: github.com/salman-ir.
